# 📝 SmartWork - Smart Todo Application

A full-stack todo application built with React, Node.js, MongoDB and AI integration.

## 🚀 Live Demo
- Frontend: Coming Soon
- Backend API: Coming Soon
- API Docs: Coming Soon

## ✨ Features
- ✅ User Authentication (Register/Login)
- ➕ Add, Edit, Delete Tasks
- 🔴 Priority System (High, Medium, Low)
- 📚 Task Categories (Study, Work, Personal, Shopping)
- 🔍 Search with Autocomplete
- 📊 Task Statistics & Charts
- ⏰ Alarm Reminders with Snooze
- 🤖 AI Task Suggestions (Gemini AI)
- 🎉 Confetti Animation on Completion
- 🌙 Dark/Light Mode Toggle
- 📋 Next Task Queue
- 📱 Responsive Design


## 🛠️ Tech Stack

## Frontend:
- React.js
- React Router DOM
- Recharts (Statistics)
- Canvas Confetti
- React Toastify
- Axios

### Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcryptjs
- Swagger API Docs
- Google Gemini AI
